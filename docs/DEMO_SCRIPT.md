# Five-minute pitch script

## 0:00–0:35 — Problem

“Most commerce assistants recommend products but stop before the hard part: a safe transaction. AgentCart AI closes that loop while keeping the customer in control.”

## 0:35–1:15 — Natural-language goal

Choose **Build a premium desk audio setup under ₹15,000**. Point out the structured cart, transparent reasoning, stock check and budget evidence.

## 1:15–2:00 — Agent architecture

Explain that the LLM proposes catalog IDs, while deterministic code validates those IDs, recomputes the price and enforces the ₹20,000 limit. Say: “The model proposes; policy decides.”

## 2:00–2:45 — Gated checkout

Select **Review & approve order**. Show the preflight checks and explain that the server cannot create an order until explicit approval is sent.

## 2:45–3:35 — Graceful failure

Create the test order and choose **Simulate authentication failure**. Show that the agent stops, does not retry, preserves the order and offers an alternative method.

## 3:35–4:15 — Successful recovery

Choose the alternative method, then simulate success. Open the Audit Trail and show the original intent, gate, failure, recovery and capture.

## 4:15–5:00 — Business value and close

“AgentCart AI can increase basket relevance and AOV without granting an AI unrestricted payment authority. It is explainable, bounded, gated, testable and ready to connect to Razorpay test mode.”
