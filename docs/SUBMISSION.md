## Project name / title

AgentCart AI — Explainable, Bounded Commerce Agent

## Project objective

AgentCart AI converts a customer’s natural-language shopping goal into a budget-aware product bundle, explains every recommendation, and waits for explicit approval before creating a Razorpay test-mode order. It helps merchants grow average order value through relevant cross-sell while keeping every money action bounded, gated and auditable. The system validates model output against a trusted catalog, recalculates prices server-side, enforces a strict action ceiling, records a complete decision trail and handles payment failure safely without uncontrolled retries.
